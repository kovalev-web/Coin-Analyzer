Popup Components
Shell classes — базовые классы 4 типов
.popupПлавающие попапы — bg paper, border steel, radius-xl, shadow, overflow:hidden, max-width:100vw-8px
.overlayПолноэкранные оверлеи — position:fixed, inset:0, display:none. Открывается через .open или style.display
.context-menuКонтекстные меню — тот же визуальный шелл что .popup, анимация 0.1s
.dropdownDropdown меню — display:none, position:absolute. Видим через .dropdown.open
Internal structure — используется внутри .popup
.popup-headerpadding: 16px 12px 0 — flex, align-items:center, gap:8px
.popup-bodypadding: 16px 12px 0
.popup-footermargin-top: 16px, padding: 0 12px 16px
Animations
popup-inopacity 0→1 + translateY(-4px→0). .popup / .context-menu: 0.15s / 0.1s. .dropdown.open: 0.12s
overlay-inopacity 0→1, 0.2s. Используется в .overlay
prefers-reduced-motionВсе анимации попапов отключаются
